# Samuel Omobuwa — Data Analyst Portfolio

A responsive, multi-page portfolio for Samuel Omobuwa, a data analyst focused on customer insights, business intelligence, and operational performance. Built with HTML, CSS, and vanilla JavaScript.

## Pages

- `index.html` — Introduction, selected projects, and skills overview
- `about.html` — Professional experience, education, skills, and certifications
- `projects.html` — Analytics, machine-learning, and automation projects linked to GitHub
- `planner.html` — Local task planner with browser storage
- `contact.html` — LinkedIn, email, CV, and WhatsApp contact options

## Features

- Responsive navigation and layouts
- Light and night themes, with the selected theme saved in the browser
- Animated homepage headline with reduced-motion support
- Planner tasks saved in `localStorage`
- Contact form that validates input and opens a prefilled email in the visitor's email application
- Editable WhatsApp message template
- CV links for viewing and downloading from Google Drive

## Run locally

No build step or package installation is required. From the project folder, run:

```powershell
python -m http.server 8000
```

Then open <http://localhost:8000> in a browser. Stop the server with `Ctrl+C`.

## Project links

Project cards link to their respective GitHub repositories. The `how-market` repository is private and may require access. The weather dashboard uses simulated readings and is a monitoring prototype, not a validated forecasting model.

## External assets

Raleway is loaded from Google Fonts, and project/portfolio imagery is hosted by Unsplash. An internet connection is needed for these remote assets.
